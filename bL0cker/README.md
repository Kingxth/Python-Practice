# bL0cker

A Python tool designed to prevent procrastination, boost mental agility, and encourage fast critical thinking through math challenges.

## Overview

`bL0cker` runs quietly in the background and monitors your system for specific target applications (such as games, launchers, or web browsers). If you try to open a restricted application without permission, the script instantly terminates the process and opens a strict mathematical examination interface. 

To regain access to your application, you must successfully complete a series of random math exercises generated by a custom calculation module (`calculos.py`). If you lose all your lives, a temporary penalty block is enforced with a countdown timer.

## Features

- **Procrastination Control:** Automatically detects and blocks target processes before they fully open.
- **Math Agility:** Integrates multiple operation types (addition, subtraction, multiplication, division, powers, and roots) across different difficulty levels.
- **Graphical User Interface:** Built with Python's `Tkinter` using a clean, modern dark mode layout, showing live timers and lives remaining.
- **Penalty System:** Enforces a timed lockout if the user fails the exercise set.
- **Custom Target App:** Easily configure any application executable to monitor through a simple setup prompt.

## Requirements

- Python 3.x
- `psutil` library

## Installation and Setup

1. Clone or download this repository.
2. Open your terminal inside the project folder.
3. Create and activate a virtual environment:
   ```bash

   source venv/bin/activate
