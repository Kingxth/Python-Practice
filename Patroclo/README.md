# Patroclo
Patroclo is a simple web application built with Python and Flask to help you orgnize your files. It takes files from a source folder and sorts them into subfolders based on their extensions.


## What it does?
- Sorts files into gategories automatically
- Creates a backup zip file of your source folder before making any changes
- Renames duplicate files safely so nothing gets overwritten
- Keeps a log of every action, which you can check directly from the web interface.
