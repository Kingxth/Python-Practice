# Simple Calculitiez

A lightweight web application built for math entertainment and rapid mental calculation practice. Designed for people who want to improve their speed and agility with simple mathematical operations under pressure.

## Why I Built This
This is a personal initiative born out of my own drive to improve my fast mathematical logic, test my limits under a strict time constraint (90-second sessions), and sharpen my mental calculation skills through code.

## Tech Stack
* Python / Flask: Backend logic, route handling, and state management.
* SQLite: Local database to track match history, scores, response times, and streaks.
* HTML5 / CSS3 / JavaScript: Clean, responsive, and dynamic user interface.

## Features
* Customizable Difficulties: Adjust the complexity for additions, subtractions, multiplications, divisions, powers, and roots.
* Timed Sessions: A fast-paced 90-second game mode to push your limits.
* Live HUD: Real-time tracking of score, current streak, and time remaining.
* Dashboard and Analytics: Track your global stats, accuracy percentage, average response time, and recent match history.
