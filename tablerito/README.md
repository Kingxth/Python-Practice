# Tablerito
A simple real time collaborative board built with Python, Flask, and Websockets.
I made this project to practice and because I couldn't find any virtual board out there matched my tastes :D

## What you need

Before starting, make sure you have instaleld :
 - Python ( 3.10 )
## How to run it
1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/tablerito.git](https://github.com/your-username/tablerito.git)
   cd tablerito 
   python -m venv venv
   source venv/bin/activate```
2. ** install dependencies*
	``` pip install -r requirements.txt ```
3. ** run the app
	``` python app.py ```
