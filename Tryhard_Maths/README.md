# Tryhard Maths
** Tryhard Maths ** is an interactive web application built with Python, Flask  and SQLite designed to help students and math enthusiasts to improve their mental calculation skills

## What it does

- Dynamic Exercises : Generates randomized math problems, including basics ( arithmetic ) and advanced topics ( derivatives )
- Dynamic Difficulty ( Scaling ) : Automatically adjust the difficulty based on your performance.
- Dashboard : Provides visual statistics, historical game and more...

## The purpose 
The main goal of this project is to move away from static boring math. Improve in simple aspects like arithmetic, but also perform complex calculations like in derivatives (simple) and also integrals.

## tech Stack
- Backend: Python, Flask, SQlite
- Frontend: HTML, CSS, JS, Chart.js
- Environment: ( venv)

## How to run it 

Follo these steps to set up and run the project:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/your-username/Tryhard_Maths.git](https://github.com/your-username/Tryhard_Maths.git)
   cd Tryhard_Maths```
2. ```python3 -m venv venv
      source venv/bin/activate```
3. ``` pip install flask```
4. python src/app.py
5. Finally, open the your browser and go to ```http://127.0.0.1:5000```
